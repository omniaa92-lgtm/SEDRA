# N SEDRA | سدرة

موقع تعريفي من صفحة واحدة لبوتيك **N SEDRA** للمصممة نجلاء العمري في جدة، حي النهضة.

## الملفات
- `index.html`: الموقع كاملاً (وضع فاتح وداكن، ونموذج طلب يُرسل عبر واتساب)
- `images/`: الشعار والصور وأيقونات الموقع وصورة المشاركة
- `robots.txt` و`sitemap.xml` و`site.webmanifest`: ملفات تحسين الظهور في محركات البحث (SEO)
- `vercel.json`: إعدادات النشر على Vercel

## النشر على Vercel
1. ادخلي على vercel.com وسجّلي الدخول بحساب GitHub.
2. اضغطي **Add New → Project**، ثم اختاري المستودع `SEDRA` واضغطي **Import**.
3. اسم المشروع: `n-sedra` (بهذا يصبح الرابط `https://n-sedra.vercel.app`).
4. اختاري **Framework Preset: Other**، واتركي Build Command وOutput Directory فارغين.
5. اضغطي **Deploy**.

> إذا تغيّر الرابط (مثلاً بسبب حجز الاسم أو ربط دومين خاص)، استبدلي `https://n-sedra.vercel.app` بالرابط الجديد في `index.html` و`robots.txt` و`sitemap.xml`.

## بعد النشر
- أضيفي الموقع إلى Google Search Console وأرسلي ملف `sitemap.xml`.
- أنشئي ملفاً تجارياً في Google Business Profile باسم "سدرة N SEDRA" في حي النهضة بجدة. هذا أهم خطوة للظهور في البحث المحلي.
- ضعي رابط الموقع في البايو على انستغرام وسناب شات وتيك توك.

## روابط سناب شات وتيك توك
عدّلي `SOCIAL` أسفل `index.html`، وأضيفي الروابط نفسها إلى `sameAs` في وسم `ld+json` أعلى الملف.
